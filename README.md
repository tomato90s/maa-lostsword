## 使用方法

### 1. 下载 Release

从 [Releases](https://github.com/tomato90s/maa-lostsword/releases) 页面下载对应平台的安装包。

支持平台：
- Windows (x64 / ARM64)
- macOS (x64 / ARM64)

### 2. 自动更新

启动时会自动检查并下载资源更新，无需手动重新下载完整安装包。

- **更新范围**：`agent/`（Python 脚本）、`resource/`（任务配置）、`interface.json`
- **更新源**：自动尝试 GitHub 直连及多个镜像加速节点（`gh-proxy.com` 等）
- **下载反馈**：日志区域会显示实时进度、下载速度和文件大小

如果自动更新失败，仍可手动从 Releases 页面下载完整包覆盖。

### 3. 运行

解压后运行对应的可执行文件：

- **Windows**: `MaaLostSword.exe`
- **macOS**: `MaaLostSword.app`（首次运行可能需要手动签名）

### 4. 连接设备

支持 ADB 连接模拟器或物理设备。推荐使用 BlueStacks、MuMu 等安卓模拟器运行游戏。

### 5. 启动任务

- **模拟器自带加速**：可自动打开游戏进行任务
- **使用第三方加速器**：需手动打开并登录游戏，在游戏大厅启动任务

### 6. 任务选项

- **竞技场**：次数是本轮上限，票券和免费机会提前用尽时正常结束；需要钻石或费用无法确认时不继续挑战。
- **副本**：金币、经验书、属性石和活动免费次数可分别选择；巨石阵默认关闭，开启后在免费扫荡结束并返回副本列表后执行。
- **公会**：投资默认关闭，捐献上限默认0。
- **商店**：每日免费礼包独立处理；消耗品、突袭、公会、竞技场、夏日币和南瓜币分类分别开启，按预设商品清单批量兑换。分类开关默认关闭；活动分类不存在时跳过。
- **秘密奶牛副本**：“使用自定义次数”默认关闭，忽略数值框，只完成游戏剩余的免费次数，用完自动跳过。开启后可设置0至99，默认10，作为本周脚本使用铃铛的次数上限，免费次数另算；0表示只用免费次数。例如本周脚本尚未使用铃铛，设置10次且剩3次免费时，会免费打3次、再用铃铛打10次。每轮取得战利品后退场；遇到5秒自动重试的结算页，会先关闭自动再次挑战再返回，并核对次数及铃铛；铃铛不足时结束，不自动购买补充。
- **迷宫（每周任务）**：每周一次，检测到游戏内本周已完成时自动跳过，不必每天取消勾选。从战斗→普通最右侧进入，保留游戏里的难度和路线设置。选卡默认优先石头→经验宝箱→金币宝箱，可调整顺序；三种资源都没有时，可选择其他资源或停止等待。跳过骷髅交易和明确会使队员阵亡的选项，未知剧情保留画面并停止。
- **宝石合成**：默认1轮，用于每日任务；游戏每轮处理自动选中的整批材料并收取页面显示的金币，并非只合成一颗。普通、高级、稀有可合成，紫色英雄或更高品质、品质未知时停止。设置0可跳过。
- **闪退后自动拉起游戏**：位于“启动游戏”的子选项，默认开启。运行中确认游戏进程退出后，每轮最多拉起2次，每次登录等待最多180秒；回到大厅后继续后续任务，中断项保留失败状态，不重复执行已发起的消费或挑战。关闭后不检查进程、不拉起游戏；助手空闲或模拟器退出不在恢复范围内。
- **领取任务奖励**：建议放在最后；每日、每周、史诗页签检查完成后返回大厅。

## 环境要求

- [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 运行环境
- **安卓模拟器**：推荐使用 BlueStacks、MuMu 等模拟器运行游戏（暂不支持 iOS 设备）
- **游戏语言**：简体中文（OCR 文字识别依赖中文界面）
- ADB 调试连接
- 游戏分辨率/DPI：推荐 1920x1080，280DPI

## 开发说明

本项目使用 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 作为底层自动化框架，通过图像识别（OCR + 模板匹配）实现游戏操作的自动化。

Pipeline 配置文件位于 `assets/resource/pipeline/`，使用 JSON 格式定义识别节点和操作逻辑。

更多开发文档请参考 [MaaFramework 文档](https://github.com/MaaXYZ/MaaFramework/tree/main/docs)。

安装 `requirements.txt` 和 `tools/requirements.txt` 中的 Python 依赖后，可运行不连接游戏的流程及打包测试：

```shell
python -m unittest discover -s tests -v
```
